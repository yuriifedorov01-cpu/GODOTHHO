## Общие правила и ограничения
- **Исходная папка (`D:\PERENOS`)**: СТРОГО ТОЛЬКО ДЛЯ ЧТЕНИЯ (Read-Only). Никакие файлы в ней не изменяются и не добавляются.
- **Папка исходного веб-клиента (`D:\HHT_CLIENT`)**: Скачанный полный клиент из репозитория `https://github.com/yuriifedorov01-cpu/hht-client` (`MyGame.swf`, `data/`, `dynamic_content/`, `SFX_and_music/`, `cut-scenes/`, `includes/`) — также используется как Read-Only источник.
- **Рабочая папка Godot-проекта (`D:\PERENOS_GODOT`)**: Все новые файлы, распакованные ресурсы, декомпилированный исходный код, инструменты и сам клиент Godot 4.3 размещаются здесь.
- **Экономия токенов**: Работа ведется строго по [TOKEN_RULES.md](file:///d:/PERENOS_GODOT/TOKEN_RULES.md).
- **Документация**: Для всех API Godot 4 используется MCP `context7` (`/websites/godotengine_en_stable`).
